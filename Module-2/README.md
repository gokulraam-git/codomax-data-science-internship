#  Cricket Player Performance Data Analysis

##  Overview

This project is part of the **Data Science Internship at Codomax Digital Solution**.

The project focuses on analyzing cricket player performance data using **Python, Pandas, and NumPy**. The dataset is explored, cleaned, and analyzed to obtain useful insights about player performance.

> **Note:** The dataset contains fictional/sample values created for educational purposes.

##  Objectives

- Import a CSV dataset into Google Colab
- Explore and understand the dataset using Pandas
- Perform basic data analysis
- Identify and handle missing values
- Detect and remove duplicate records
- Perform numerical analysis using NumPy
- Identify top-performing players

##  Technologies Used

- Python
- Pandas
- NumPy
- Google Colab
- CSV Dataset

##  Dataset

The dataset contains cricket player performance information with the following attributes:

- Player Name
- Team
- Matches
- Runs
- Batting Average
- Strike Rate
- Fours
- Sixes
- Wickets
- Bowling Average
- Economy Rate
- Catches

##  Data Analysis Performed

### Pandas
- Dataset loading
- Data exploration
- Statistical summary
- Filtering and sorting
- Team-wise analysis
- Missing value detection
- Duplicate detection and removal

### NumPy
- Mean
- Median
- Minimum
- Maximum
- Standard deviation
- Numerical array operations

##  Data Cleaning

The dataset was cleaned by:

- Identifying missing values
- Filling missing numerical values using the median
- Detecting duplicate records
- Removing duplicate records
- Checking data types

##  Final Analysis

The project identifies:

- Top run scorer
- Top wicket taker
- Player with the highest batting average
- Team-wise average runs
