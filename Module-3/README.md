# Cricket Player Performance Data Visualization

## Overview

This project is part of the **Data Science Internship at Codomax Digital Solution**.

The project focuses on visualizing cricket player performance data using **Python, Matplotlib, and Seaborn**.

Different charts are created to understand player performance, team distribution, data patterns, and relationships between cricket statistics.

> **Note:** The dataset contains fictional/sample values created for educational purposes.

## Objectives

- Visualize cricket player performance data
- Create different types of charts using Matplotlib and Seaborn
- Identify patterns and trends from the data
- Understand relationships between different performance metrics
- Present data in an easy-to-understand visual format

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- CSV Dataset

## Visualizations Created

### 1. Bar Chart
Used to compare the **Top 10 run scorers**.

### 2. Line Chart
Used to observe the variation between **matches played and runs scored**.

### 3. Pie Chart
Used to show the **distribution of players across teams**.

### 4. Histogram
Used to understand the **distribution of runs** among players.

### 5. Scatter Plot
Used to analyze the relationship between **batting average and runs**.

## Key Insights

- The bar chart helps identify the top run-scoring players.
- The line chart shows how runs vary with matches played.
- The pie chart represents the team-wise player distribution.
- The histogram shows how runs are distributed among players.
- The scatter plot helps understand the relationship between batting average and runs.
