# 🏏 Cricket Player Runs Prediction using Machine Learning

## 📌 Overview

This project is part of the **Data Science Internship at Codomax Digital Solution**.

The project focuses on building a beginner-friendly Machine Learning model to predict cricket player runs based on selected player performance statistics.

A **Linear Regression** model from Scikit-learn is used to train the model, make predictions, and evaluate its performance.

> **Note:** The dataset contains fictional/sample values created for educational purposes.

## 🎯 Objectives

- Understand the basics of Machine Learning
- Prepare cricket player performance data for Machine Learning
- Select relevant input features and target variable
- Split the dataset into training and testing sets
- Train a Linear Regression model
- Predict player runs
- Evaluate model performance using regression metrics
- Test the model with sample player statistics

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- CSV Dataset

## 🤖 Machine Learning Approach

### Learning Type

**Supervised Learning**

The model learns from existing cricket player data where the actual number of runs is already available.

### Algorithm

**Linear Regression**

Linear Regression is used to predict a numerical target value based on one or more input features.

## 📊 Features Used

The following player performance statistics are used as input features:

- Matches
- Batting Average
- Strike Rate
- Fours
- Sixes

### Target Variable

**Runs**

The model predicts the total runs based on the selected performance statistics.
